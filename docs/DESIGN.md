# Design System

## Style
- Clone of AWS Route53 Console
- Professional, dense, data-heavy, utility-focused.

## Typography
- AWS uses Amazon Ember. If unavailable, Helvetica Neue, Arial, or similar sans-serif.

## Colors (AWS Console approximation)
- **Header:** Dark Navy/Black (#232F3E)
- **Background:** Light Gray/White (#F2F3F3 or #FFFFFF)
- **Primary Button:** Orange (#EC7211)
- **Secondary Button:** White with gray border
- **Text:** Dark Gray (#16191F)
- **Links:** Blue (#0073BB)

## Components
- **Sidebar Navigation:** Expandable/collapsible sections.
- **Tables:** Data grids with filtering, pagination, selection checkboxes.
- **Forms:** Labeled inputs, descriptive helper text beneath inputs.
- **Modals:** Centered dialogs with confirmation actions.

## UX Requirements
- Notifications/Toast messages for success/error on CRUD operations.
- Loading spinners or skeleton screens during API requests.
- Consistent empty states for tables with no data.
- Search and filter bars above tables.
