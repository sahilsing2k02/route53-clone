# Development Rules

## General
- Use TypeScript for Frontend.
- Use Python for Backend.
- Match AWS UI/UX closely.

## UI
- Follow DESIGN.md strictly.
- Build reusable UI components (e.g., AWSTable, AWSButton, AWSInput).

## Backend
- Validate all incoming API requests (Pydantic in FastAPI).
- Implement basic error handling.

## Testing
- Ensure core workflows (auth, create zone, create record) work end-to-end.

## Git
- Make logical, self-contained commits.
